# Licensing map

Weekly Penguin Timeline uses different licences for different classes of material.

| Material | Licence |
| --- | --- |
| Source code | MIT |
| Project documentation | CC BY 4.0 |
| Original penguin artwork in `public/penguins/` and its generated derivatives | CC BY-NC 4.0 |
| Third-party assets, logos, trademarks, and branding | Not licensed by this repository; respective rights-holder terms apply |

The root `LICENSE` applies to source code. See `LICENSE-DOCUMENTATION.md`, `LICENSE-ARTWORK.md`, and `THIRD_PARTY_NOTICES.md` for the other scopes.

Where a file contains material from more than one class, the relevant licence applies to each part according to its nature. Third-party rights always take precedence over the project-level grants for material the project does not own.
